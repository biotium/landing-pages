# SfN 2026: HubSpot landing page

`sfn-2026-paste-into-design-manager.html` is generated by `python3 tools/build-pages.py` from `../page.yaml` and `../../shared/`. Don't edit it by hand.

It's self-contained: CSS and JS are inlined, and every image (portfolio, resources, team headshots, Biotium Choice icon, merch) is embedded, so nothing needs uploading. The only outside requests are Google Fonts and the Wistia scripts for the MiniMab video.

Merging to `main` deploys it to Design Manager (`Landing Pages/sfn-2026.html`) through `.github/workflows/deploy-hubspot.yml`. Pasting it into Design Manager by hand still works as a fallback.
