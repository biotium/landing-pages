# ASCB Cell Bio 2026: HubSpot landing page

`ascb-cell-bio-2026-paste-into-design-manager.html` is generated by `python3 tools/build-pages.py` from `../page.yaml` and `../../shared/`. Don't edit it by hand.

Images are inlined, except the ones listed in `../design/hosted-images.json`, which point at copies already hosted on learn.biotium.com.

Merging to `main` deploys it to Design Manager (`Landing Pages/ascb-cell-bio-2026.html`) through `.github/workflows/deploy-hubspot.yml`. Pasting it into Design Manager by hand still works as a fallback.
